# ⌨️ Educational Keylogger Simulator

A beginner-friendly Python project that demonstrates how keyloggers work by capturing keyboard inputs in real-time.

## 🎯 Features
- Captures keystrokes live
- Displays normal and special keys
- Stops safely using ESC key
- Runs locally for educational purposes

## 🛠 Requirements
Python 3  
pynput library

Install dependency:
pip install pynput

## ▶️ How to Run
python keylogger_simulator.py

## ⚠️ Disclaimer
This project is strictly for educational purposes to understand how keyloggers work. Do not use on systems without permission.
